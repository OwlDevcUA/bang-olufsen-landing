# Landing Page - Bang & Olufsen
A modern and responsive landing page built for Bang & Olufsen. This project demonstrates high-end audio product presentation, seamlessly combining clean design, dynamic elements, and a premium user experience.

## Live Demo
DEMO: [Bang & Olufsen Demo](https://owldevcua.github.io/bang-olufsen-landing/)

## Technologies Used

### Core
* **HTML5** – Page structure & semantic markup
* **SCSS** (v7.0+) – Styling & pre-processing

### Build Tool & Bundler
* **Parcel** (v2.12.0) – Web application bundler
* **@parcel/transformer-sass** (v2.12.0) – SCSS compilation

### Code Quality & Formatting
* **ESLint** (v8.57.0) – JavaScript linting
* **Stylelint** (v16.7.0) – SCSS/CSS linting & formatting
* **Linthtml** (v0.9.6) – HTML linting
* **Prettier** (v3.3.2) – Code formatting
